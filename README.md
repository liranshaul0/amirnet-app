# AMIRNET — הכנה למבחן אמיר״ם

אפליקציית תרגול לבחינת הסיווג באנגלית (אמיר״ם / אמירנ״ט): תרגול אדפטיבי, סימולציות מבחן
במבנה הרשמי, אוצר מילים עם חזרות מרווחות (SRS), מעבדת טעויות וסטטיסטיקות.

## שתי דרכים להריץ

### 1. סטטי (ברירת המחדל — GitHub Pages)

`index.html` הוא אפליקציה עצמאית לחלוטין: כל השאלות, המילון והלוגיקה בתוכו,
והנתונים נשמרים ב-localStorage. פשוט פותחים את הקובץ בדפדפן, או מגישים את התיקייה
בכל שרת סטטי. ניתן להתקנה כאפליקציה (PWA) ועובד גם ללא חיבור לרשת.

בגרסה הזו כפתורי ה-AI **מוסתרים אוטומטית** — אין להם שרת לדבר איתו.

### 2. עם AI (חינם, בלי מפתח) — Cloudflare Pages

מוסיף שני פיצ'רים: **חונך AI** שמנתח שאלה שנענתה, ו**מחולל אסוציאציות זיכרון** למילים.

הדרך המומלצת היא Cloudflare Pages עם Workers AI: אין מפתח API, אין כרטיס אשראי,
והאתר וה-API על אותו דומיין. הוראות מלאות: [DEPLOY.md](DEPLOY.md).

### 3. הרצה מקומית עם Gemini (אופציונלי)

```bash
npm install
cp .env.example .env.local   # ואז מלאו GEMINI_API_KEY
npm run dev                  # http://localhost:3000
```

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה — UI, לוגיקה, שאלות ומילון |
| `server.js` | שרת Express אופציונלי: `/api/ai-tutor`, `/api/ai-mnemonic`, `/api/ai-health` |
| `sw.js` / `manifest.webmanifest` | תמיכת PWA (התקנה ועבודה offline) |
| `docs/superpowers/specs/` | אפיון העיצוב וההיסטוריה שלו |

## אבטחה

`GEMINI_API_KEY` נקרא **רק בצד השרת**. אל תכניסו אותו ל-`index.html` ואל תדחפו
קובץ `.env` לריפו — `.gitignore` כבר חוסם את זה.

## עיצוב

כהה/בהיר של המערכת**, עם מתג לעקיפה ידנית. ללא אימוג'ים בממשק — אייקוני SVG בלבד.
